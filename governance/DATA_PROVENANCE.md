# Data Provenance Standard

Every released research dataset should identify source, retrieval time, vintage where available, license/redistribution status, raw reference, transformation pipeline, schema, missingness treatment, calendar/timezone, hashes, code commit, and known limitations.

A silent refresh is not a dataset update. New observations or vendor revisions require a new version or a recorded immutable snapshot for the study using them.

Licensed data may be referenced without redistribution. A public proxy dataset must not be described as a bit-for-bit reproduction of a licensed historical input.
