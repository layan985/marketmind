# Software Release Policy

A MarketMind release records semantic version, source commit, changelog, compatibility statement, tests, controlled-audit status where applicable, known limitations, deprecations, and archive/citation information.

Research specifications tied to a frozen release remain tied to that release even when later software improves. Later releases cannot silently replace the code named by a preregistration or reproduction record.

Critical research regressions trigger a correction notice and, where needed, a new patch release rather than an unannounced artifact replacement.
