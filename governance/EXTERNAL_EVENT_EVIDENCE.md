# External Event Evidence Standard

External activity becomes permanent evidence only when the project records what happened, what artifact was exposed, and what the external party actually did. A logo, meeting, view count or informal compliment is not counted as validation by itself.

For talks and webinars, retain the event page, slides, recording when permitted, repository release, bounded attendee questions and any resulting correction or research note. For independent benchmark runs, retain the exact code/version, predictions, metrics, differences and author credit. For methodological review, retain the reviewer scope, dated comments, response and resulting change. For errors, retain the original claim, discrepancy, correction and impact assessment.

The machine-readable source is `registry/external_events.csv`.
