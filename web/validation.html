03 / WHAT WOULD CHANGE OUR MIND?

Falsification belongs on the public site.

CLAIM

Network connectivity contains structurally meaningful information.

WOULD WEAKEN IT

If simpler average correlation reproduces classifications across universes and perturbations.

CLAIM

Information-flow measures identify directional structure.

WOULD WEAKEN IT

If direction frequently reverses under small lag, sample or common-driver conditioning changes.

CLAIM

Multiscale regime measurement adds value over simpler state models.

WOULD WEAKEN IT

If simple baselines match stability, separation and generalization.

CLAIM

The displayed MII combination is meaningful.

WOULD WEAKEN IT

If equal weights, one component, or a distilled simple rule reproduce the same state map.

06 / NEGATIVE RESULTS

Failure stays in the record.

These are not labeled as failed prospective claims. They are controlled warnings that now become benchmark requirements.
