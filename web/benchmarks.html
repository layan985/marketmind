02 / ACCEPTANCE PHILOSOPHY

Complexity pays rent.

A component survives only if it contributes stable information, improves discrimination, changes a scientifically relevant conclusion, or survives perturbations better than its simpler comparator.

If average correlation reproduces a network classifier, publish that. If equal weights reproduce MII, publish that. If weekly sampling destroys the state map, publish that.
