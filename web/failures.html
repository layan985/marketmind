Failure is not a footnote.
It is a research object.

This page distinguishes controlled fragility from a failed prospective hypothesis. MarketMind will not upgrade a warning into a grand failure claim, and it will not downgrade adverse evidence into a disappearing changelog entry.

01 / CURRENT CONTROLLED FRAGILITIES
F-CTRL-001LAB-v0.1

Naive directional information is vulnerable to a common driver.

In A → B and A → C with no B → C path, naive B→C transfer entropy rose as shared-driver strength increased. Conditioning on A reduced the high-strength estimate by ~59%, while finite-sample estimator floor remained visible.

EFFECT ON PROGRAM

Common-driver conditioning, sample-size maps and null false-positive rates are mandatory in MM-BENCH-004.

F-CTRL-002LAB-v0.1

A highly correlated network metric can still change state labels after hub removal.

The full and hub-removed metric series correlated at 0.995, yet 7.2% of fixed-threshold labels changed.

EFFECT ON PROGRAM

Universe perturbation and transition-date drift are mandatory in MM-BENCH-006.

F-CTRL-003LAB-v0.1

One outlier moved Pearson dependence far more than Spearman dependence.

Across 100 controlled replications, the mean absolute Pearson change was 12.26× the Spearman change.

EFFECT ON PROGRAM

Robust dependence alternatives and outlier stress tests are mandatory in network benchmarking.

03 / THE RULE

A later fix does not delete the original evidence.

Every adverse result should record the claim, configuration, version, evidence, interpretation, corrective action and whether the correction itself was retested. A null stays citable even if the implementation later improves.
