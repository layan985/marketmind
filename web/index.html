01 / THE CLAIM CEILING

Detection is not attribution.
Attribution is not identification.

The rule is deliberately severe: report no stronger interpretation than the strongest claim level whose required falsification tests survive. A method can be useful at C0 while failing C2. A causal model can succeed by abstaining when C3 is not identifiable.
