# MarketMind Research Applications

The application series records actual research use rather than repository attention metrics.

## Required record

Every `MM-APP-*` application states:

- researcher and affiliation where applicable;
- internal or external authorship;
- research question;
- market/data source and version;
- MarketMind release and commit;
- configuration;
- code/notebook location;
- outputs;
- limitations;
- citation or persistent archive when available.
