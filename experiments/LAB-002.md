# LAB-002 — Leakage Machine

**Status:** COMPLETE · RESULT AVAILABLE  
**Ground truth:** IID Gaussian returns; genuine predictive structure is zero.

## Question
How much apparent risk-adjusted performance can common timing and selection mistakes manufacture when the underlying returns contain no genuine predictive structure?

## DGP and estimator
Each run draws 4,000 IID N(0,0.01) returns. Annualized Sharpe = √252 × mean(strategy return) / sample standard deviation. 100 replications, seeds 1000–1099.

## Arms
1. Causal trailing control: 20-session rolling mean shifted one session.
2. Centered 21-session rolling window: future observations enter the feature.
3. Same-session execution: the signal is sign(r_t) and receives r_t.
4. Retrospective threshold: best of 17 cutoffs chosen after observing realized noise.
5. Best of 50 independent noise signals.

## Interpretation boundary
These values measure contamination in one disclosed synthetic design. They do not estimate bias in any specific published strategy. The same-session arm is intentionally pathological.
