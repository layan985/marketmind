# Institutional research

MarketMind already contains the assurance and executable benchmark layer required for institutional delivery.

- `CLIENT_ASSURANCE_PROTOCOL.md`
- `CLIENT_DELIVERY_CHECKLIST.md`
- `MODEL_RISK_REGISTER.md`
- `PUBLIC_BENCHMARK_PROTOCOL.md`
- `marketmind.benchmark.run_benchmark_bundle`

The benchmark engine produces a 14-artifact evidence package rather than a detached dashboard result.

## Quant Research Integrity Audit

Inspect data timing, feature availability, normalization, labels, execution, costs, parameter selection, validation design, multiple testing, holdout contamination and artifact reproducibility.

## Market Structure Study

Produce memory, information-flow, network and regime analysis with uncertainty, sensitivity, comparison to conventional models, provenance and a reproducible package.

Commercial sponsorship does not create scientific validation status.
