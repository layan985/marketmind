# Software

MarketMind is the open implementation layer of the research program. The software surface is documented separately from research claims so package functionality, controlled tests, real-market applications and prospective evidence are not collapsed into one status.

## Release contract

Every software release should identify the code version, environment, test state, benchmark artifacts, changed assumptions, known failures, compatibility notes and research consequences. A passing test suite is implementation evidence, not evidence that the economic theory is true.

## Evidence boundary

`SYNTHETIC`, `REAL PUBLIC DATA`, `INDEPENDENT REPRODUCTION`, `EXTERNAL REVIEW` and prospective holdout evidence are distinct. No internal rerun is promoted into an external evidence class.
