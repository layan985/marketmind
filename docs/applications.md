# Applications

Applications are outside or internal research uses of MarketMind on a defined market, dataset and question. They are not endorsements and they do not become external-use evidence until the user and use are attributable.

## Application record

A publishable application should state:

- application ID and date;
- researcher or institution when permission allows;
- market and data source;
- research question;
- MarketMind version and configuration;
- outputs used;
- deviations from the reference methodology;
- result summary;
- limitations;
- reproduction status;
- evidence class.
