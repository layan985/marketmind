# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and semantic
versioning.

## [Unreleased]

## [0.2.0] - 2026-08-13

### Added

- Executable preregistered H1/H2/H3 strategy construction and study-level inference.
- Paired synchronized moving-block Sharpe comparisons and Holm-corrected mechanism tests.
- Deterministic seven-check research audit with disclosed latent structure and fail-closed CLI.
- Hash-verifiable numerical result bundles and a frozen v0.2.0 audit evidence pack.

### Fixed

- CLI and pipeline metadata now use one package-version source instead of stale hard-coded values.
- Deterministic demos now bind result metadata to the input fingerprint and data manifest.

## [0.1.1] - 2026-08-08

### Added

- Public OSF preregistration and associated OSF project links.
- Field-by-field OSF preregistration copy sheet and submission metadata.
- Frozen prospective validation configuration for the 2026-08-10 through 2027-08-06 holdout.
- Machine-readable deviation log and dedicated preregistration freeze branch.
- ORCID-linked citation, CodeMeta, and Zenodo metadata.

### Changed

- Expanded Zenodo metadata for open-science and reproducibility archiving.
- Updated software citation metadata to identify the preregistered prospective validation.

## [0.1.0] - 2026-08-07

### Added

- Paper-aligned MII estimator with memory, information-flow, and connectivity components.
- DFA Hurst, Higuchi dimension, Shannon entropy, KSG mutual information, and transfer entropy.
- Dynamic correlation networks, weighted clustering, and Prim minimum spanning trees.
- Causal rolling-tercile regime classification.
- Nine fixed technical signals and cost-aware walk-forward evaluation.
- Naive baselines, transaction-cost sweeps, block bootstrap, reality check, and deflated Sharpe.
- Reproducible public-data pipeline, provenance manifests, CLI, dashboard, notebooks, and docs.
- Cross-version CI, trusted PyPI publishing workflow, and Zenodo citation metadata.
