# External Methodological Review Template

## Scope

One bounded question only. Examples include:

- Is the rolling normalization contract genuinely ex ante?
- Are directional-information settings defensible under known confounding structures?
- Are network metrics duplicative?
- Is the prospective inference specification appropriate?
- Can the API be used in a way that silently violates timing assumptions?

## Findings

For each finding record severity, evidence, reviewer reasoning, maintainer response, change made, and whether disagreement remains.

A methodological review is not an endorsement. Critical or negative findings remain public with the response.
