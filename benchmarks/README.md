# MarketMind Benchmark Program

A benchmark is specified before its comparative result is interpreted. Competitors are selected because they are reasonable alternatives, not because they are easy to beat.

## Registered study specifications

| ID | Question | Status |
| --- | --- | --- |
| MM-BENCH-001 | Does multiscale structure improve regime discrimination beyond simpler state models? | specified; not yet frozen with results |
| MM-BENCH-002 | How much apparent performance inflation can common leakage errors create? | specified; not yet frozen with results |
| MM-BENCH-003 | Do MarketMind network metrics contain distinct information? | specified; not yet frozen with results |
| MM-BENCH-004 | When does directional-information estimation succeed or fail under known structure? | specified; not yet frozen with results |

Each completed benchmark must publish configuration, data version, code commit, environment, comparator implementation, acceptance metrics, all prespecified results, negative findings, and a machine-readable registry entry.
